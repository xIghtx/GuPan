# 프로젝트 설명

## 연구 주제

**재귀 자가학습 붕괴 궤적 비교**

## 리빙랩 문제 정의

고등학생이 수행평가와 탐구 활동에서 AI 답변이나 인터넷 요약 자료를 사용할 때, 원자료를 확인하지 않고 재가공된 정보를 그대로 사용하는 문제가 발생할 수 있다.

## 적용 방향

재귀학습 실험에서 관찰한 반복 증가, 표현 다양성 감소, 문맥 손실, 언어 이탈 등의 현상을 연구 근거로 삼고, 실제 사용자는 다음 과정으로 정보를 검증한다.

1. 현재 정보 입력
2. 추가 확인이 필요한 정도 확인
3. 핵심 단서와 숫자·날짜 확인
4. 자동 생성된 검색어로 원자료 탐색
5. 찾은 원문과 현재 정보 비교
6. 수행평가나 탐구 보고서에 검증된 근거 사용

## 대상 사용자

AI와 인터넷 자료를 이용해 수행평가, 탐구 보고서, 발표 자료를 작성하는 고등학생

## 핵심 가치

AI 사용을 막는 것이 아니라, AI를 사용한 뒤 **출처 확인과 원문 검증까지 이어지는 습관**을 만드는 것을 목표로 한다.
