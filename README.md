재귀 자가학습 붕괴 궤적 비교 — Living Lab
AI가 생성한 정보를 반복적으로 재사용할 때 나타나는 정보 열화 현상을 연구하고, 그 결과를 고등학생의 수행평가·탐구 활동에서 실제로 사용할 수 있는 정보 검증 도구로 연결한 웹 프로젝트입니다.
주요 기능
정보 확인 필요도 분석
원문/현재 정보 직접 비교
핵심 단서·숫자·날짜·문맥 보존 정도 확인
원정보 검색어 자동 생성
Gen0~Gen8 재귀학습 붕괴 궤적 탐색
연구 근거와 실험 결과 설명
다크 모드 / 라이트 모드
TXT, MD, CSV, JSON, HTML, XML, PDF, DOCX 파일 입력
리빙랩 사용자 기록 및 CSV 내보내기
실행 방법
별도 빌드 과정이 필요하지 않습니다.
`index.html`을 브라우저에서 엽니다.
또는 GitHub Pages를 활성화해 웹으로 배포합니다.
> PDF/DOCX 읽기 기능은 외부 CDN 라이브러리를 사용하므로 인터넷 연결이 필요합니다.
파일 구성
```text
.
├── index.html
├── README.md
├── samples/
│   ├── gen0_original.txt
│   └── gen8_collapsed.txt
└── docs/
    └── PROJECT_NOTES.md
```
테스트 데이터
`samples/` 폴더에는 같은 주제에서 출발한 비교용 텍스트가 있습니다.
`gen0_original.txt`: 비교적 정상적인 0세대 원문 예시
`gen8_collapsed.txt`: 반복·문맥 손실·언어 이탈이 심해진 8세대 예시
이 두 파일은 사이트의 `원문` / `현재 정보` 입력 칸에 넣어 비교 기능을 확인할 때 사용할 수 있습니다.
주의
이 사이트의 `정보 확인 필요도` 점수는 AI 생성 여부나 실제 정보 손실률을 확정하는 판별기가 아닙니다. 반복, 표현 쏠림, 언어 혼합, 숫자 반복 등의 신호를 바탕으로 추가 검증이 필요한 정도를 보여주는 교육용 지표입니다.
연구 배경
프로젝트의 연구 배경은 재귀적으로 AI 생성 데이터를 학습할 때 발생하는 모델 붕괴와 저자원 언어의 변화입니다. 서비스 부분에서는 이 연구 결과를 그대로 현실의 임의 텍스트에 단정적으로 적용하지 않고, 학생이 원자료를 찾고 비교하는 과정을 지원하는 방향으로 사용합니다.
